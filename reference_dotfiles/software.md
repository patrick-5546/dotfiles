# Software

Other software I've used on Windows. Unlike the CLI tools in [mise's config](../dot_config/mise/config.toml) and the
[desktop apps](../.chezmoidata/desktop-apps.toml), the dotfiles don't install it. Search for it in UniGetUI, one of the
desktop apps, or install it with `winget install --exact --id <ID>`.

| Software | What it does | winget ID |
| --- | --- | --- |
| [Carnac](https://github.com/Code52/carnac) | Shows the keys you press, for presentations and screen recordings | `code52.Carnac` |
| [Discord](https://discord.com) | Chat | `Discord.Discord` |
| [NanaZip](https://github.com/M2Team/NanaZip) | Opens and creates archives. A 7-Zip fork that's in the Windows 11 context menu | `M2Team.NanaZip` |
| [Plex](https://www.plex.tv) | Plays media from Plex servers | `Plex.Plex` |
| [Rufus](https://rufus.ie) | Creates bootable USB drives | `Rufus.Rufus` |
| [Signal](https://signal.org) | Encrypted messaging | `OpenWhisperSystems.Signal` |
| [TeamViewer](https://www.teamviewer.com) | Remote access and support | `TeamViewer.TeamViewer` |
| [Thunderbird](https://www.thunderbird.net) | Email | `Mozilla.Thunderbird` |
| [Windows Terminal](https://github.com/microsoft/terminal) | Terminal, preinstalled on Windows 11. My settings are in [`windows_terminal/`](./windows_terminal/) | `Microsoft.WindowsTerminal` |
| [WSL](https://learn.microsoft.com/windows/wsl/) | Runs Linux, which the dotfiles also support. `wsl --install` installs it with Ubuntu. My config is in [`wsl/`](./wsl/) | `Microsoft.WSL` |
